============================================================
   HWP 자동 수식 입력기
============================================================

📌 프로그램 소개
-----------------
웹 브라우저에서 수식을 입력하면 자동으로 HWP 문서에 삽입해주는 프로그램입니다.


📦 필수 파일
-----------------
1. hwp_server.py                  - 서버 프로그램
2. hwp_auto_app.html              - 웹 인터페이스
3. start_server_and_browser.py    - 통합 실행 스크립트
4. 🚀 HWP수식입력기_실행.bat       - 실행 파일


🚀 사용 방법
-----------------
1. "🚀 HWP수식입력기_실행.bat" 파일을 더블클릭하여 실행
2. 서버가 새 창에서 시작됩니다
3. 서버 준비가 완료되면 자동으로 브라우저가 열립니다
4. HWP 문서에서 원하는 위치에 커서를 두거나 텍스트를 드래그
5. 웹 페이지에서 수식을 입력하고 "HWP에 수식 삽입" 버튼 클릭
6. 수식이 자동으로 HWP에 삽입됩니다!


💡 주요 기능
-----------------
✅ 자동 포트 설정 - 포트 충돌 시 자동으로 다른 포트 사용
✅ 드래그 텍스트 자동 삭제 - 선택된 텍스트를 수식으로 자동 대체
✅ 실시간 서버 연결 확인 - 5초마다 서버 상태 자동 체크
✅ 수식 예제 제공 - 클릭 한 번으로 예제 입력


📝 수식 입력 예제
-----------------
- RM{A} over {B}          → A/B 분수
- x^2 + y^2 = z^2         → 피타고라스 정리
- sqrt {x^2 + y^2}        → 제곱근
- overline {AB}^{2}       → 오버라인


⚙️ 필수 요구사항
-----------------
- Python 3.x 설치 필요
- pyhwpx 라이브러리 설치 필요 (pip install pyhwpx)
- 한글(HWP) 프로그램 설치 필요


🔧 서버 종료 방법
-----------------
- 서버 창에서 Ctrl + C 누르기
- 또는 작업 관리자에서 Python 프로세스 종료


📞 문제 해결
-----------------
Q. 서버 연결이 안 됩니다
A. 서버만_시작.bat 파일을 먼저 실행했는지 확인하세요

Q. 포트 오류가 발생합니다
A. 자동으로 다른 포트를 찾습니다. 그래도 안 되면 서버를 재시작하세요

Q. 수식이 삽입되지 않습니다
A. HWP가 실행 중인지, 문서가 열려있는지 확인하세요
